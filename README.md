# Philosophische Denkschulen – Abhängigkeitsgraph

**[→ Zur Lernseite](https://s540d.github.io/philosophen/start.html)**

Ein interaktiver Lern-Graph der westlichen Philosophiegeschichte – für alle, die verstehen wollen, wie die großen Denkschulen zusammenhängen, sich beeinflussen und voneinander abgrenzen.

## Was dich erwartet

- **22 Denkschulen** von der Antike bis ins 20. Jahrhundert
- **Verbindungen** zwischen den Schulen: *beeinflusst*, *setzt fort*, *kritisiert / bricht mit*, *synthetisiert*
- **Detailansicht** pro Schule: Kernthese, Vertiefung, bedeutende Vertreter, alle Verbindungen
- **Suche, Lernfortschritt und Favoriten**, vier **Lernpfade**, ein **Quiz** zu jeder Schule und eine **Zeitleiste**
- Epochen: Antike · Mittelalter · Neuzeit · 19. Jahrhundert · 20. Jahrhundert

## So benutzt du die Seite

1. Knoten mit der Maus berühren → die Verbindungen werden hervorgehoben.
2. Knoten anklicken (am Handy antippen) → die Detailansicht öffnet sich.
3. Auf eine freie Fläche oder `✕` klicken → Detailansicht schließen.
